# Audit trail ekstraksi

Folder ini menyimpan laporan QA otomatis dan catatan batas ekstraksi. Notebook pada folder `Bab*/` tetap merupakan hasil ekstraksi yang sedang diaudit, bukan notebook kanonis yang sudah disahkan. Jangan menganggap notebook sebagai versi rilis sebelum setiap blok kode dicocokkan dengan Word Master dan hasilnya diverifikasi.

Laporan Putaran 1 dan Putaran 2 menjelaskan metode ekstraksi dan keterbatasannya. Laporan Putaran 3 menambahkan screening parse dan eksekusi sel secara berurutan.
